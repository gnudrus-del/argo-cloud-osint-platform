# Support

Thanks for using Argo Cloud OSINT Platform. Choose the channel that fits your question:

## Where to go

| I want to… | Channel |
| --- | --- |
| Ask an open question about how to use Argo | [Discussions](https://github.com/gnudrus-del/argo-cloud-osint-platform/discussions) |
| Report a reproducible bug | [New issue → Bug report](https://github.com/gnudrus-del/argo-cloud-osint-platform/issues/new?template=bug_report.yml) |
| Propose a feature or a new connector | [New issue → Feature request](https://github.com/gnudrus-del/argo-cloud-osint-platform/issues/new?template=feature_request.yml) |
| Report a **security vulnerability** (private) | [Security Advisories](https://github.com/gnudrus-del/argo-cloud-osint-platform/security/advisories/new) — **not** a public issue |
| Read installation and configuration docs | [`docs/`](docs/) |

## Before opening an issue

1. Search existing [issues](https://github.com/gnudrus-del/argo-cloud-osint-platform/issues) and [discussions](https://github.com/gnudrus-del/argo-cloud-osint-platform/discussions).
2. Read the [`docs/FAQ.md`](docs/FAQ.md).
3. Confirm you are on the latest release. Include the version in your report.
4. **Redact** anything that identifies a real person, host, organization, or contains real credentials or API keys.

## What Argo maintainers do *not* provide

- Personalized investigation advice for a specific target.
- Bypasses for platform rate limits or Terms of Service.
- Support for non-defensive, non-authorized, or privacy-invasive workflows.

If you need commercial support, integration help, or an audited deployment, open a Discussion — commercial support channels are not yet in place, and this is tracked as a roadmap item.
