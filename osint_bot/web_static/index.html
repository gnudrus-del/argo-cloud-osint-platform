Azioni suggerite

Routing OPSEC

controllato dal piano

L'OPSEC routing e gestito automaticamente dal planner in base al caso, al tipo di target e ai flag di autorizzazione.

  • Standard protetto: default per target autorizzati senza necessita di isolamento.
  • Mozilla/Firefox dedicato: attivato se la sorgente richiede un profilo separato.
  • Tor isolato: obbligatorio per dark/deep web flaggato.
  • Multi-provider: usato quando esistono API configurate per piu motori.

Audit e logging

Gratuito
  • Audit log con hash chain SHA-256 — ogni evento e tracciabile.
  • Login con IP loggato per accountability.
  • Email di verifica obbligatoria al primo signup.
  • Sessioni HttpOnly, CSRF, Secure cookie.
  • GDPR by-design: DSAR export/erase, tombstone, RoPA.
